# UI

Open `index.html` in a browser (double-click or Live Server).

1. Paste your ngrok base URL (no trailing slash).
2. Wait for the status pill: **API: ok**.
3. **Send** — streaming chat (`/ask/stream`), optional RAG sources.
4. **Verify** — claim check (`/verify`) with tool trace.

History is stored in `localStorage` on this machine only.
